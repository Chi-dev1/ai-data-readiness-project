# AI-Readiness-Starts-with-Data-Quality
# Overview
This project demonstrates how poor data quality can impact analytical outcomes and limit the effectiveness of AI-driven decision-making. Using a sample dataset, I simulate common data issues such as missing values, duplication, and inconsistencies, and analyze how these issues affect data reliability.
# Key-Insight
Organizations cannot successfully implement advanced analytics or AI systems without first establishing clean, structured, and reliable data. Poor data quality leads to misleading insights, which can ultimately undermine decision-making processes.
# Process
	•	Simulated real-world data issues (missing values, duplicates)
	•	Analyzed how these issues distort results
	•	Applied data cleaning techniques
	•	Compared outcomes before and after cleaning
# Tools Used
	•	Python (Pandas, NumPy)
	•	Data cleaning techniques
	•	Basic visualization (Matplotlib)
# Outcome
This project reinforces the importance of data governance and preparation as foundational components of the analytics lifecycle, particularly in the context of AI implementation.
